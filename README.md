# Homebrew Tap for Buzz

Personal Homebrew tap for [block/buzz](https://github.com/block/buzz).

## Install

```sh
brew install --cask aboutdomtime/buzz/buzz
```

Seeded from upstream release `desktop-v0.5.3`.

## Updating

`.github/workflows/update-cask.yml` checks the latest upstream GitHub release every day and commits cask version and SHA-256 updates when a new release is available. The workflow can also be run manually.
